# Google Flow Prompts: Section 1 (Test Run)

These are the 3D, Pixar-style shots. The data and text graphics (clocks, switches, charts, counters) are built separately as code motion graphics, so every prompt here is **character and biology only, with no on-screen text.** AI video can't spell reliably, so labels are added in the edit.

---

## HOW TO USE THESE IN FLOW (read once)

> **Every prompt now starts with its file name** (for example `S01-B03_3D_VisceralFatHug_v1.`). Flow names each download from the first words of the prompt, so the file arrives already named. Flow adds a date/time on the end, which is fine to keep. For a second take, change `_v1` to `_v2` at the start of the prompt before generating.

1. **Make the characters first (Step A).** Paste each character prompt, pick the best image, and save it to Flow's Ingredients. *(Section 1 characters are done ✅ and saved in `02_flow_prompts/characters/`.)*
2. **Then make the video shots (Step B)** using **Ingredients to Video**. Add the character images listed under "Ingredients", then paste the prompt.
   - If Ingredients isn't available, use **Frames to Video**: generate the "Start frame" image first, then animate it with the video prompt.
3. **Settings:** 16:9 landscape, highest quality allowed, 2 variations if you can. Clips are ~8 s; the timing sheet in `README.md` says which part to use.
4. **Audio:** mute Flow's sound in CapCut (Volume 0). My sound effects are baked into the motion graphics, and Beth's voice carries the 3D shots.
5. **Download** at 1080p and drop it into that section's folder, e.g. `03_graphics/S01_MetabolicSwitch/`.
6. **If a label from the prompt ever shows up as on-screen text** (rare), re-roll and move the file name to the *end* of the prompt instead.

## IF A SHOT COMES OUT WRONG

- **Characters look different from the sheets:** re-run with the Ingredients attached, and add *"exactly matching the reference characters"* to the start of the prompt.
- **Gory or too realistic:** add *"cute, family-friendly, stylised cartoon, not realistic, not gory"*.
- **Unwanted text or labels appear:** add *"absolutely no text or letters anywhere"*.
- **Too slow:** add *"fast-paced, energetic, snappy motion"*.
