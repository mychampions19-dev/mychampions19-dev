## IF A SHOT COMES OUT WRONG
- **Characters don't match:** re-run with the Ingredients attached and add *"exactly matching the reference characters"* at the start (after the file name).
- **Too dark (bedroom shot):** add *"clearly visible, bright rim light on the character"*.
- **Unwanted text or labels:** add *"absolutely no text or letters anywhere"*. If the file name appears as text, move it to the end of the prompt.
